## 🇺🇸 English

### 📖 About the Project
**ASCII Wallpapers** is a lightweight Android application that renders 3D shapes using characters (ASCII art) and brings them to life right on your home screen. No heavy OpenGL required — just pure math, Canvas, and a bit of magic.

### ✨ Features
*   **3D Shapes:** Watch a spinning Torus (donut), Sphere, and Cube.
*   **Full Customization:**
    *   🎨 **Colors:** Terminal green, amber, and classic white.
    *   ⚡ **Speed:** Adjust the rotation speed of the shapes.
    *   🔍 **Size:** Change the size of the ASCII characters (zoom in/out).
*   **Live Settings:** Changes apply instantly without needing to restart or reapply the wallpaper.
*   **Modern UI:** Supports edge-to-edge displays, dark mode, and notch cutouts.

### 🚀 How to Build
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Ascii_Wallpapers.git


2. Open the project in Android Studio.
3. Sync Gradle and run the app on your device/emulator.
4. Once installed, go to your phone's Settings -> Wallpaper -> Live Wallpapers, find ASCII Wallpapers, and apply it!

Note for Release: To build a signed APK, use Build -> Generate Signed Bundle / APK in Android Studio. Keep your .jks keystore file safe!

🛠️ Built With

· Kotlin

· Material Design Components

🇷🇺 Русский

📖 О проекте

ASCII Wallpapers — это легковесное приложение для Android, которое отрисовывает 3D-фигуры с помощью символов (ASCII-арт) и оживляет их прямо на вашем рабочем столе. Здесь нет тяжелого OpenGL — только чистая математика, Canvas и немного магии.

✨ Особенности

· 3D-фигуры: Вращающийся Тор (бесконечная лента/пончик), Сфера и Куб.
· Полная кастомизация:
  · 🎨 Цвета: Классический терминальный зеленый, янтарный и белый.
  · ⚡ Скорость: Регулировка скорости вращения фигур.
  · 🔍 Размер: Изменение размера символов (приближение и отдаление).
· Живые настройки: Изменения применяются мгновенно, обои не нужно перезапускать или устанавливать заново.
· Современный интерфейс: Поддержка вырезов в экране (челок), темной темы и edge-to-edge отображения.

🚀 Как собрать

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Ascii_Wallpapers.git
   ```
2. Откройте проект в Android Studio.
3. Синхронизируйте Gradle и запустите проект на телефоне/эмуляторе.
4. После установки зайдите в настройки телефона: Обои -> Живые обои, найдите ASCII Wallpapers и установите их!

Примечание для релиза: Чтобы собрать подписанный APK, используйте Build -> Generate Signed Bundle / APK в Android Studio. Обязательно сохраните файл ключа .jks в надежном месте!

🛠️ Технологии
